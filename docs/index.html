Подключите HT2000 и запустите монитор

Нужны Linux с hidraw, Python 3, PyQt5 и графическая сессия с системным треем. Основное окружение проекта — Astra Linux 1.8 / Fly.

Поддерживаемое устройство: SLAB HT2000, USB VID 10c4, PID 82cd. Backend для Windows и macOS не реализован.

Полная инструкция установки →

Сначала установите PyQt5 средствами дистрибутива и настройте udev-права на устройство по инструкции.

git clone https://github.com/ishmyak/HT2000.git
cd HT2000
python3 ht2000_monitor.py

# Запуск в фоне
bash start_ht2000.sh start

# Остановка
bash start_ht2000.sh stop

Доступ по сети — под вашим контролем

Включённый сервер слушает все сетевые интерфейсы на первом свободном порту 8080–8089. Аутентификации и TLS нет: используйте доверенную сеть и ограничивайте доступ межсетевым экраном. Не открывайте порт напрямую в Интернет.

Безопасность и данные →

Открытый код. Понятное устройство.

PyQt5 отвечает за трей; чтение USB, CSV и веб-сервер используют стандартную библиотеку Python. Данные сохраняются рядом с приложением. Диапазоны комфорта настраиваются пользователем и не являются медицинской оценкой.
