# HT2000 Monitor

Показывает в системном трее данные с CO2-монитора SLAB HT2000 (VID 0x10c4,
PID 0x82cd, USB HID): одна иконка-квадрат с графиком **CO2** и плашкой-бейджем
текущего значения числом (плашка красится по уровню: зелёный < 800 ppm,
жёлтый 800–1200, красный > 1200; текст — контрастный к плашке, 18px bold,
читаем при масштабировании треем). **Температура и влажность — в хинте**
иконки с отметками нормы по СанПиН. Раз в минуту все три параметра пишутся
в CSV-файл.

Возможности иконки и меню:

- текущее значение CO2 числом на плашке-бейдже (цвет плашки — по уровню);
- одноразовые системные уведомления при подъёме CO2 (>= 800 и >= 1200 ppm);
- мигающий красный «!» при потере связи (тултип — сколько минут);
- клик по иконке — открыть веб-страницу (сервер стартует автоматически);
- меню: «Открыть веб-страницу», «Сервер: порт/выкл», «Пауза записи»,
  «Открыть папку данных», «Выход».

Контекстное меню иконки содержит пункт **«Сервер»** (чекбокс): при включении
поднимается мини веб-сервер (стандартная библиотека, порт 8080..8089, первый
свободный), отдающий страницу с текущими измерениями:

- `http://127.0.0.1:8080/?range=hour|day|week` — HTML-страница, обновляется
  JS-ом **без перезагрузки** каждые 5 секунд;
- тёмная тема (кнопка, запоминается), favicon вкладки окрашен по уровню CO2;
- статусные бейджи норм у температуры и влажности (✓ зелёный — норма,
  ⚠ жёлтый — вне оптимума в допустимой зоне, ⚠ красный — вне допустимой;
  подсказка — направление и зоны);
- статус «обновлено … N с назад» / «связь потеряна · данные N мин назад»;
- SVG-графики CO₂, температуры и влажности за час/сутки/неделю из файла
  данных: сводка мин/сред/макс под графиком (+ нормы: оптимальная и
  допустимая), полупрозрачные зоны нормы на графиках T/RH, маркеры точек,
  синхронный crosshair (навёл на точку — значение и время на всех трёх
  графиках), линия «сейчас»;
- время проветривания (11:00, 13:00, 14:30, 16:00) — вертикальные пунктирные
  линии с подсветкой 30-минутного интервала после проветривания и легендой;
- `http://127.0.0.1:8080/data` — текущие данные в JSON (включая статусы норм);
- адрес дополнительно показывается в хинте иконки.

## Нормы микроклимата (температура для офиса)

Тёплый сезон — май–сентябрь, холодный — октябрь–апрель (модуль `comfort.py`).
Для температуры заданы две зоны: **оптимальная** и **допустимая**
(значения настроены пользователем):

| Величина | Зона | Холодный сезон | Тёплый сезон |
|----------|------|----------------|--------------|
| Температура | оптимальная | 22–24 °C | 23–25 °C |
| Температура | допустимая | 20–25 °C | 21–28 °C |
| Влажность | норма | 40–60 % | 40–60 % |

Статусы:

- ✓ зелёный — в норме (оптимальной зоне);
- ⚠ жёлтый — вне оптимальной, но в допустимой зоне (у влажности — ниже нормы);
- ⚠ красный — вне допустимой зоны (у влажности — выше нормы).

Отклонения показываются в хинте иконки, бейджами на веб-странице и зонами
нормы на графиках (допустимая — бледная полоса, оптимальная — ярче).

### Настройка норм (config.json)

Диапазоны переопределяются файлом (без него — значения из таблицы выше).
Поиск: сначала `~/.config/ht2000/config.json`, затем `config.json` рядом
с модулями проекта. Битые значения игнорируются (дефолты), о повреждённом
JSON сообщается в stderr.

```json
{
  "cold": {
    "temperature_optimal": [22, 24],
    "temperature_acceptable": [20, 25],
    "humidity_optimal": [40, 60],
    "humidity_acceptable": [40, 60]
  },
  "warm": {
    "temperature_optimal": [23, 25],
    "temperature_acceptable": [21, 28],
    "humidity_optimal": [40, 60],
    "humidity_acceptable": [40, 60]
  }
}
```

Любой ключ можно опустить — возьмётся значение по умолчанию. Допустимые
диапазоны можно не задавать (тогда равны оптимальным — как у влажности).

Данные пишутся в файл, **именованный датой**: `data/ht2000_ГГГГ-ММ-ДД.csv`
(новый день — новый файл, в течение дня — один и тот же).
Графики на странице читаются из этого файла; при суточном диапазоне берутся
вчерашний и сегодняшний файлы.

Основано на проекте [trayinfo](https://github.com/mik/trayinfo) (панель часов,
цвета иконок, отрисовка графиков).

## Протокол устройства

HT2000 общается через HID *feature reports* (ioctl `HIDIOCSFEATURE` /
`HIDIOCGFEATURE`), обычный write/read в hidraw не работает:

1. `Set Feature`, report 0x05, данные `ff ff ff` — запрос свежего снимка;
2. `Get Feature`, report 0x05 — ответ ≥ 30 байт:
   - байты `[7:9]` (big-endian) — температура, `(v - 400) / 10` °C;
   - байты `[9:11]` (big-endian) — влажность, `v / 10` %;
   - байты `[24:26]` (big-endian) — CO2, ppm.

Протокол реверс-инжинирирован сообществом
(https://github.com/tomvanbraeckel/slab_ht2000), проверен на живом устройстве.

## Установка прав на устройство

`/dev/hidraw*` по умолчанию доступен только root. Один раз:

```bash
sudo cp 99-ht2000.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger
```

## Запуск

```bash
python3 ht2000_monitor.py
```

Данные пишутся в `data/ht2000_ГГГГ-ММ-ДД.csv` (разделитель `;`):

```
datetime;co2_ppm;temp_c;rh_percent
2026-10-19 12:20:01;715;25.7;30.0
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

## Файлы

- `ht2000_reader.py` — чтение и разбор данных с устройства (без GUI);
- `ht2000_monitor.py` — приложение: иконка CO2 в трее + запись в файл;
- `ht2000_web.py` — мини веб-сервер (HTML-страница и JSON);
- `tests/` — тесты парсера, поиска устройства и веб-сервера;
- `99-ht2000.rules` — udev-правило для доступа к hidraw без root.
