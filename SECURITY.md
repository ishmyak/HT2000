# Безопасность

## Границы применения

HT2000 Monitor — локальное приложение для чтения USB-датчика.
Веб-сервер слушает `0.0.0.0` на первом свободном порту 8080–8089.
Аутентификации и TLS нет. Ограничивайте доступ средствами сети и ОС;
не перенаправляйте этот порт из Интернета. Отключайте сервер через меню,
если доступ к графикам не нужен.

Правило `99-ht2000.rules` даёт всем локальным пользователям чтение и запись
к соответствующему HID-устройству (`0666`). Для многопользовательских машин
нужна локальная политика прав. Не запускайте GUI от root.

CSV содержат временные отметки и параметры помещения; они могут раскрывать
распорядок его использования. Не добавляйте реальные данные, журналы,
локальную конфигурацию и сетевые адреса в публичные Issues или коммиты.

## Сообщение о проблеме

Для уязвимостей используйте приватное сообщение через GitHub Security Advisory,
если оно включено в репозитории. Не публикуйте секреты и эксплуатационные
подробности в открытом Issue. Гарантированного срока ответа и отдельной
программы вознаграждений у проекта нет.
