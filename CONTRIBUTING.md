# Участие в разработке

Опишите проблему в Issue: версия Linux, Python, рабочий стол, модель датчика,
ожидаемое поведение и шаги воспроизведения. Удалите личные и сетевые данные
из журналов и примеров.

Изменения отправляйте отдельным pull request. Сохраняйте разделение GUI,
чтения устройства, CSV и веб-интерфейса. Не добавляйте сторонние зависимости
в логику чтения и веб-сервера без обоснования.

Перед отправкой:

```bash
python3 -m unittest discover -s tests -v
bash -n start_ht2000.sh
git diff --check
```

Для сетевых тестов нужны локальные сокеты без проксирования localhost.
Тестовые CSV создавайте во временных каталогах. Не подключайте реальные
данные измерений к тестам. Если меняется HID-обмен или GUI, отдельно укажите,
проверяли ли вы изменения на настоящем устройстве и в графической сессии.
